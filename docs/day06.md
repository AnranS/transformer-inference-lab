## 任务 2：手算完整 Attention（70 分钟）

**这是今天最重要的任务。** 纸笔算，算完再用 notebook 核对。

### 公式

```text
Q = X Wq      K = X Wk      V = X Wv

Attention(Q, K, V) = softmax( Q Kᵀ / sqrt(Dh) ) V
```

### 三者的语义

| 角色 | 一句话 | 类比 |
|---|---|---|
| **Q**（Query） | 当前 token **想找什么** | 检索时输入的关键词 |
| **K**（Key） | 每个 token **可被怎样匹配** | 文档的索引标签 |
| **V**（Value） | 匹配上之后**真正聚合的信息** | 文档的正文内容 |

关键认识：**Q、K、V 都是同一份 hidden states 的线性投影**。
所谓「self-attention」的 self，就是指这三者同源。

### 手算题目

为了能手算，取 `Wq = Wk = Wv = I`（单位矩阵），于是 `Q = K = V = X`。
4 个 token，`D = Dh = 4`：

```text
X = [[1, 0, 1, 0],
     [0, 1, 0, 1],
     [1, 1, 0, 0],
     [0, 0, 1, 1]]
```

按顺序算，每一步都写下来：

**第 1 步：`Q Kᵀ`**（4×4，就是 `X` 和自己每一行的点积）

**第 2 步：除以 `sqrt(Dh)` = 2**

**第 3 步：对最后一维做 softmax**

**第 4 步：`probs @ V`**

### 核对答案

算完再看。用 notebook 验证，这些数字我已经确认和 `F.scaled_dot_product_attention` 完全一致：

```text
第 1 步  QKᵀ = [[2, 0, 1, 1],
                [0, 2, 1, 1],
                [1, 1, 2, 0],
                [1, 1, 0, 2]]

第 2 步  ÷2  = [[1.0, 0.0, 0.5, 0.5],
                [0.0, 1.0, 0.5, 0.5],
                [0.5, 0.5, 1.0, 0.0],
                [0.5, 0.5, 0.0, 1.0]]

第 3 步  softmax 第 0 行 = [0.3875, 0.1425, 0.2350, 0.2350]
第 4 步  输出   第 0 行 = [0.6225, 0.3775, 0.6225, 0.3775]
```

第 3 步的手算：`exp(1)=2.7183`、`exp(0)=1`、`exp(0.5)=1.6487`，
和为 `7.0157`，逐个相除即可。

**再算一遍，这次加 causal mask**（位置 `i` 只能看 `0..i`，其余置 `-inf` 再 softmax）：

```text
加 mask 后 第 0 行 = [1.0000, 0.0000, 0.0000, 0.0000]
加 mask 后 第 3 行 = [0.2350, 0.2350, 0.1425, 0.3875]
```

第 0 行变成 one-hot 是必然的——它只能看自己，softmax 一个元素恒为 1。
**这条性质以后可以当断言用**：任何 causal attention 实现，
第 0 行的概率必须是 `[1, 0, 0, ...]`，不满足就是 mask 写错了。

### 为什么要除以 `sqrt(Dh)`

必须能自己推一遍。设 `q`、`k` 各维独立、均值 0、方差 1，则：

```text
q · k = Σ(q_i k_i)，共 Dh 项
每项方差 1 → 点积方差 = Dh → 标准差 = sqrt(Dh)
```

**方差随 `Dh` 线性增长**。`Dh=128` 时点积典型量级已到 ±11，
softmax 进入饱和区：最大值吃掉几乎全部概率，其余接近 0。后果是

- 训练时：梯度趋近 0，学不动
- 推理时：分布过尖，attention 退化成「只看一个 token」

除以 `sqrt(Dh)` 把方差拉回 1，与 `Dh` 无关。

> **注意是 `Dh` 不是 `D`。** 这是 Day 9 的高频 bug——多头情况下每个 head 的维度是 `Dh = D / Hq`，
> 用 `D` 会把分数压得过小。

## 今日最重要的面试式问题

**为什么要除以 `sqrt(Dh)`，不除会怎样？**

点积由 `Dh` 项求和构成，方差随 `Dh` 线性增长。不除的话 `Dh` 越大分数越极端，
softmax 饱和：训练梯度消失，推理分布过尖。除 `sqrt(Dh)` 让方差回到 1，与 `Dh` 解耦。

追问：**为什么是 `sqrt(Dh)` 而不是 `sqrt(D)`？**

因为 Attention 在**每个 head 内部**独立计算，参与点积的向量维度是 `Dh = D / Hq`，
不是 `D`。写成 `D` 会让分数偏小、分布过平。
